## Issues

- [api-enhanced #305](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/issues/305)：Linux 多用户共享 /tmp/xeapi_public_key 导致权限错误。TuneWeave 公钥状态为进程内缓存，不使用这个共享临时路径。
- [api-enhanced #300](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/issues/300)：取流返回 -460 风控仍是未关闭问题，不作为已修复功能发布。TuneWeave 保留上游业务失败诊断。
- [musicdl #105](https://github.com/CharlesPikachu/musicdl/issues/105)：汽水加密 M4A 无法播放仍未关闭。TuneWeave 已有独立授权媒体解析及解密，不据此放宽密钥、媒体身份或容器校验。
- QQMusicApi #309 的 CDN 问题已关闭，但该仓库没有相对基线的新提交；不把关闭状态当作新增补丁。
- 酷狗 20028 / v_type=38 等设备验证问题仍在未关闭列表中，没有本次可直接移植的新修复。

本次审计没有发现应直接替换 TuneWeave 现有实现的已验证上游修复；保留 beta.4 已合入的功能与修复，另行完成发布前全仓回归。
