# B 站平台功能扩展候选池

B 站的正式完成状态只看[项目范围覆盖账本](../bilibili-scope.md)。本文件只登记项目范围之外、但未来可能直接增强音视频检索、整理或播放体验的能力；不建立覆盖全部 B 站业务的分母。

候选状态为：

- `candidate`：已登记，但没有实施计划；
- `selected`：因明确需求被选入具体扩展任务；
- `implemented`：已实现；
- `rejected`：经评估不再考虑或确定超出项目边界。

候选池没有完成率、清零要求或固定实施时间。专栏、直播、漫画、游戏、钱包、装扮和纯社交能力不因存在公开接口而自动成为候选；只有出现具体媒体用途时才登记。当前没有已登记的 B 站扩展候选。
