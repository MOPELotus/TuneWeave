# 汽水音乐项目范围覆盖账本

汽水音乐以官方分享页、官方 PC 客户端和官方 API 的真实请求为协议基线。开源项目只用于拼接候选协议、字段模型和能力边界；任何请求链在进入 TuneWeave 前都必须重新验证，不得依赖维护者个人账户、共享 Cookie 池、远程第三方解析站或机械翻译的源码。

状态沿用其他平台项目范围账本：`pending` 尚未实现，`deferred` 已明确保留但当前条件不足，`partial` 缺少必要分支，`implemented` 已完成代码和离线验证但缺真实成功态，`verified` 已完成对应真实路径验收。当前共 20 个正式验收单元：`pending=11`、`deferred=0`、`partial=1`、`implemented=1`、`verified=7`，总项目范围完成度为 `7/20 = 35.00%`。其中首个 pre-release 所需公开音源补充层为 SD01–SD10，当前完成度 `7/10 = 70.00%`；SD06 的完整流与试听流已通过统一 HTTP 真实交付，SD07 已完成受限解密与全部已知容器分支，其中 AAC 已真实验证，待获得官方授权的 FLAC/ALAC 样本后再转为 `verified`。SD08 已完成公开歌单和两种 Uni 导入，待公开专辑收口；SD09 已完成播放、下载、本地内容、302 和跨平台严格匹配的真实验收。SF01–SU01 属于后续汽水完整项目阶段，不阻塞首个测试版。

## 公开音源补充层

| ID | 验收单元 | 状态 | 实施与验收边界 |
| --- | --- | --- | --- |
| SD01 | 官方协议与匿名设备基线 | `verified` | 官方 PC 歌曲搜索已真实消融到固定 HTTPS 入口、`aid=386088` 和查询游标，不需要 Cookie、匿名设备、`x-helios` 或 `x-medusa`；公开链不虚构或持久化无作用的设备状态，登录设备与签名生命周期留在 SF01 |
| SD02 | 分享链接与稳定歌曲身份 | `verified` | 数字 ID、`soda:` 引用及 `www.qishui.com`、`music.douyin.com`、`www.douyin.com` 三类官方歌曲 URL 归一为稳定 `soda:` 身份；短链只接受严格 `qishui.douyin.com/s/<code>`，禁用自动跳转并只检查一次受信 HTTPS `Location`，不抓取任意页面或跟随外域 |
| SD03 | 官方搜索与公开发现 | `verified` | 固定访问官方 PC 歌曲搜索并以 20 首物理页、最多 6 页实现统一任意 `offset` 与 `limit=1..100`；返回稳定歌曲身份、强类型目录音质和权益原码，不使用第三方搜索代理、共享凭据或调用方传输覆盖 |
| SD04 | 歌曲详情与公开元数据 | `verified` | 匿名 `track_v2` 以固定官方 HTTPS 参数返回歌曲、歌手、专辑、封面、时长、目录音质、统计、词曲作者、时间片段、语言、标签和分享信息；响应严格回配 ID 与媒体类型，图片域名受限，临时 player 数据不进入详情，目录存在仍不等于匿名可播 |
| SD05 | 普通、逐字与页面歌词 | `verified` | `track_v2` 的 `[行起点,行时长]<相对字偏移,字时长,保留字段>` 毫秒格式严格解析为原始逐字 KRC 与派生普通 LRC；与分享页逐句差分确认 26 行正文及 214 个字时序完全一致，页面额外两行前置信息由 contributor 表达，逐字轨始终决定格式且不被普通轨覆盖 |
| SD06 | 匿名权益、播放与试听 | `verified` | 匿名 `track_v2` player 按媒体 ID 和实际时长严格区分完整授权、精确试听窗口、无媒体授权和离线；媒体规格、有效期和 CENC 状态强类型校验且不泄漏 URL/密钥。真实统一 HTTP 已分别交付一首完整公开曲和一首 60001 ms 试听曲，试听保留原曲 107904–167905 ms 窗口，两份解密 M4A 均由 FFmpeg 完整解码 |
| SD07 | 加密媒体解密与容器重组 | `implemented` | 已独立实现严格 `spade_a`/KID 回配、`cenc`/`tenc`/`senc`、8/16 字节 IV、subsample、`stsz`/`stsc` 与 `stco`/`co64` 样本映射及原地 AES-CTR 解密；畸形 box、计数、越界、重叠、错误 scheme 和密钥代际均拒绝。AAC/ALAC 保持 ISO Base Media，FLAC 严格验证 `dfLa`、STREAMINFO、元数据末块并复用输入缓冲区重组原生 `fLaC`。真实匿名 60 秒 AAC 试听的 2,586 个样本已解密并由 FFmpeg 完整解码；匿名链尚未提供可验收的 FLAC/ALAC 授权样本，因此容器分支完成离线验证但不虚报真实成功态，且始终只处理官方已授权返回的内容 |
| SD08 | 公开专辑、歌单与 Uni 导入 | `partial` | 已接入匿名公开歌单详情、稀疏原始游标遍历和 Server/Client Uni 导入：不把可见 offset 误作上游 cursor，不按歌曲 ID 去重，并在跨页时固定核对可见总数、原始资源数和更新时间。真实 506 个原始位置过滤为 398 首可见曲，跨页窗口连续返回位置 87–90；Server 导入和 Client 物化均得到完整 398 项，Client 未落盘。待公开专辑详情、曲目及分享身份验收后转为 `verified` |
| SD09 | 统一播放、302 与 resolver | `verified` | 统一播放、下载和受限本地内容响应只返回无秘密的本站相对 URL，服务端实时刷新授权、顺序尝试受信 CDN、校验精确长度并完成 CENC 解密；完整授权可下载，仅试听明确 `available=false/url=null`，下载跳转保持 403。真实验收以网易云同名同歌手、64 ms 时长差的来源曲严格匹配到汽水公开全曲，保留 `origin_track`、0.9 匹配分和成功轨迹；播放 302 跳到本站内容端点后返回 200，最终 M4A 由 FFmpeg 完整解码 |
| SD10 | 协议、安全与真实网络验收 | `pending` | 固定官方域名、禁用任意重定向和调用方传输覆盖，限制 API、页面、歌词、加密媒体和解密输出大小；全新数据目录验证匿名设备恢复、分享、搜索或公开发现、详情、歌词、权益、播放、集合、Uni、回退及少量媒体探测 |
